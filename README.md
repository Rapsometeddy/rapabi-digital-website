# Rapabi Digital Website

A responsive, static agency website for Rapabi Digital.

## Local preview
Open `index.html` in a browser. No build step or paid service is required.

## Files
- `index.html` — page content and metadata
- `styles.css` — responsive purple-and-black visual system
- `script.js` — mobile navigation and email enquiry interaction

## Current contact setup
- Business email: rapabidigital@gmail.com
- The enquiry form prepares an email in the visitor's email app. It does not store or submit personal information to a server.
- WhatsApp contact is intentionally not linked yet because the business WhatsApp number has not been supplied. Add a verified international-format number before enabling a WhatsApp click-to-chat link.
